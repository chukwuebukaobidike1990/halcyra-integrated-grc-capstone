
# Halcyra Health Group – Integrated GRC Capstone

## Project Overview
An illustrative cross-sector Governance, Risk and Compliance (GRC) capstone exploring an integrated information security and compliance programme for a digital healthcare organisation.

## Frameworks Covered
- ISO/IEC 27001:2022
- NIST Cybersecurity Framework 2.0
- NIST SP 800-53 Rev. 5
- PCI DSS v4.0.1
- HIPAA Security Rule
- GDPR
- SOC 2 Trust Services Criteria

## Project Deliverables
1. Integrated GRC capstone report
2. Unified control matrix
3. Gap register and remediation priorities
4. ISO 27001 Statement of Applicability extract
5. 12-month assurance roadmap
6. GRC metrics and performance tracker

## Skills Demonstrated
- GRC programme development
- Enterprise risk assessment
- Regulatory and framework mapping
- Information security governance
- Control design and assurance
- Third-party risk management
- Privacy and compliance
- Audit readiness

## Important Disclaimer
This is an illustrative learning and portfolio project. It does not represent an actual client engagement, certification, formal audit opinion or regulatory approval. Framework mappings and assumptions require validation before operational use.
